# SLIET Antriksha Vigyan Club

> Official space and astronomy club website for Sant Longowal Institute of Engineering and Technology (SLIET). 

Redesigned with a modern **Light Mode UI**, an interactive starfield particle canvas, dynamic events, sky watch live alerts, team filtering, and responsive controls across all devices.

---

## ✨ Features

- **Adaptive Aesthetic:** Light Mode (default) with a Sun/Moon theme switcher saved in `localStorage`.
- **Interactive Particle Canvas:** Stargazing canvas featuring dynamic light/dark particle physics.
- **Live Astronomical Alerts:** Auto-formatting alert widget for real-time sky events.
- **Join Application Modal:** Interactive recruitment portal with instant submission feedback and direct Google Form integration.
- **Domain Wings Showcase:** Highlights specialized teams including Astronomy, Astrophysics, Tech, Satellite, and Astrophotography.
- **Interactive Events Hub:** Filter between upcoming events and past sessions.
- **Team Directory:** Filterable views for Faculty Leadership, Core Team, and Domain Leads.
- **SEO & Social Optimization:** Pre-configured Open Graph tags, Twitter Cards, and JSON-LD structured data.
- **Production Ready:** Pre-configured server optimizations via `.htaccess` for HTTPS enforcement and asset compression.
